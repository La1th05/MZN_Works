# 🚀 تعليمات تشغيل نظام إدارة التعلم الذكي

## الخطوات بالتفصيل

### الخطوة 1: فتح PowerShell
اضغط `Windows + X` واختر "Windows PowerShell" أو "Terminal"

### الخطوة 2: الانتقال إلى مجلد المشروع
```powershell
cd smart_lms
```

### الخطوة 3: إنشاء البيئة الافتراضية
```powershell
python -m venv .venv
```

### الخطوة 4: تفعيل البيئة الافتراضية
```powershell
.\.venv\Scripts\activate
```
ستظهر `(.venv)` في بداية السطر

### الخطوة 5: تثبيت المكتبات المطلوبة
```powershell
pip install -r requirements.txt
```

### الخطوة 6: إنشاء قاعدة البيانات التجريبية
```powershell
python seed.py
```

ستظهر رسالة:
```
✅ Database seeded successfully!

📝 Demo Credentials:
   Teacher: teacher@demo.com / teacher123
   Student: student@demo.com / student123
```

### الخطوة 7: تشغيل التطبيق
```powershell
streamlit run app.py
```

سيفتح المتصفح تلقائياً على: `http://localhost:8501`

## 🔑 بيانات الدخول التجريبية

### حساب المعلم
- البريد الإلكتروني: `teacher@demo.com`
- كلمة المرور: `teacher123`

### حساب الطالب
- البريد الإلكتروني: `student@demo.com`
- كلمة المرور: `student123`

## 🧪 كيفية التجربة

### كمعلم:
1. سجل الدخول بحساب المعلم
2. اذهب إلى صفحة "Teacher" من القائمة الجانبية
3. جرب:
   - إنشاء فصل دراسي جديد
   - إضافة أسئلة
   - إنشاء اختبار
   - عرض تحليلات الطلاب

### كطالب:
1. سجل الدخول بحساب الطالب
2. اذهب إلى صفحة "Student" من القائمة الجانبية
3. جرب:
   - فتح اختبار متاح
   - بدء الاختبار (سيبدأ العد التنازلي)
   - الإجابة على الأسئلة
   - إرسال الاختبار
   - عرض النتائج والتوصيات

## ❓ حل المشاكل الشائعة

### المشكلة: "python: command not found"
**الحل:** تأكد من تثبيت Python
```powershell
python --version
```
إذا لم يكن مثبتاً، حمله من: https://www.python.org/downloads/

### المشكلة: "streamlit: command not found"
**الحل:** تأكد من تفعيل البيئة الافتراضية
```powershell
.\.venv\Scripts\activate
```

### المشكلة: المنفذ مستخدم
**الحل:** استخدم منفذ آخر
```powershell
streamlit run app.py --server.port 8502
```

### المشكلة: خطأ في قاعدة البيانات
**الحل:** احذف قاعدة البيانات وأعد إنشاءها
```powershell
Remove-Item data\lms.db
python seed.py
```
