================================================================================
AI ANALYTICS ALGORITHM
================================================================================
MASTERY CALCULATION (EMA):
  alpha = 0.25
  mastery_new = alpha * accuracy + (1 - alpha) * mastery_old
  confidence = 1 - exp(-n_observations / 5)

RECOMMENDATIONS:
  if confidence < 0.35:
    "Insufficient evidence — Complete more assessments"
  elif mastery >= 0.85:
    "Student Mastered Topic — Ready for harder difficulty"
  elif mastery <= 0.60:
    "Needs Retake on Topic"
  else:
    "Progressing — Keep practicing"
