# 📚 Dyslexia Support Project

An accessible, user-centric application designed to assist individuals with dyslexia by improving readability, reducing visual stress, and providing assistive reading tools.

---

## 🌟 About the Project

Dyslexia affects how individuals process written language, often leading to challenges with reading fluency, spelling, and comprehension. Traditional digital interfaces can exacerbate these challenges due to cramped typography, low contrast, and cluttered layouts. 

This project aims to bridge that gap by implementing evidence-based accessibility features tailored specifically for dyslexic users, creating a more inclusive and seamless digital reading and learning experience.

---

## ✨ Key Features

- **Custom Typography:** Integration of dyslexia-friendly fonts (e.g., OpenDyslexic or carefully weighted sans-serif fonts) that prevent letter-confusion and crowding.
- **Adjustable Text Formatting:** Dynamic controls for letter spacing, line height, word spacing, and font size.
- **High-Contrast & Custom Themes:** Soft, tinted background color options (pastel tones) to reduce glare and visual distortion.
- **Assisted Reading Tools:** Features like reading rulers, line guides, or Text-to-Speech (TTS) integration to help users track text and comprehend content more effectively.
- **Clean & Distraction-Free UI:** Minimalist interface designed to reduce cognitive overload.
